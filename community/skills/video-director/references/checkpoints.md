# Review checkpoints

Load the current stage's files; defer later-stage implementation details until their gate opens. Read the selected type file at stage 1 and retain the brief and decisions throughout. Resolve missing answers before advancing. Explicit approval in the current conversation counts; do not repeat a gate the user already answered.

Use these short response shapes with absolute links. Bracketed entries are filled with actual outputs, not headings to copy into the film itself.

| Stage | Load now | Response shape | Advance when |
|---|---|---|---|
| 1 Brief | Selected type | “Brief: [viewer, format, length, narration, people, real inputs, media tools, rough clip cost for live-action story ads, reference videos or from scratch]. Missing: [decisions]. [brief link]. Is this right?” | Brief decisions confirmed |
| 2 Script | Visual ideas; text/captions if words appear | “[script link]. Hook: [beat]. Promise: [claim]. Turn: [change]. Proof: [visible action]. Lock this script?” | Wording/structure approved |
| 3 References | Reference films; animation styles if the user named a style | From scratch: “Building from scratch, so no reference films.” Otherwise record inspected files, timestamps and retained comparison film; disclose missing access before drawing | From scratch chosen, three inspected films, or explicit reduced coverage approval |
| 4 Directions | Animation styles, visual ideas, options rounds, frame kit, storyboard format | “[options page]. A: [idea and mechanism]. B: [different idea]. C: [if useful]. Recommend [choice and reason]. Which direction?” | Direction chosen |
| 5 Look | Options rounds; relevant media/text treatments | “[same-scene alternatives]. Decision: [one choice]. Recommend [option]. Which?” | Each look decision resolved |
| 6 Storyboard | Frame kit, visual ideas, storyboard format | “[review page]. [scene sequence and continuity]. [clip count and firm cost estimate, when clips are generated]. [open issues]. Approve or add pinned notes?” | Stills approved |
| 7 Motion | Motion library, motion spec, sound/voice, text/captions | “[spec and rebuilt page]. Total: [seconds]. [named moves, carry, easing and sound]. Conflicts: [resolved/open]. Approve?” | Motion approved |
| 8 Animated test | Build/QA; tool docs after preflight | “[checked test]. Covers: [scenes]; placeholders: [shots still stand-ins, or none]. Watched in motion: [model and fps used, findings confirmed/dismissed, or "not watched in motion" and why]. Coverage/reviews: [actual evidence]. [where the reference film wins, or where the film misses the type's numbers]. Does the movement work?” | Test approved |
| 9 Full build | Build/QA | “[numbered cut and phone copy]. Placeholders: [shots, or none]. Watched in motion: [result, or "not watched in motion"]. [changes]. Checks: [exact results, reviewed candidates, missing coverage]. [comparison]. Final or notes?” | All required checks/reviews complete and user signs off |
| 10 Polish | Polish rounds; visual ideas on ideas-pass rounds | “[numbered cut]. [each timestamped note and result]. [new checks]. Approve this round?” | Notes resolved and user signs off |

Every response reports actual limitations before its approval question. Missing tool access or measurement coverage is a hold, not a passed check; the one exception is the motion watch, which is reported as "not watched in motion" and does not hold the render. Do not generate future-stage outputs merely to fill these templates.
